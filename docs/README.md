## 目录说明

**`images/`** —— README 与使用手册引用的截图，基于 `demo` profile 的演示数据实拍，统一 1440×900。改了界面需要重拍时，步骤记在 [CLAUDE.md](../CLAUDE.md) 的「演示数据与截图」一节。

**`superpowers/specs/`** 与 **`superpowers/plans/`** —— 各功能的设计文档与实现计划，按 `YYYY-MM-DD-<主题>` 命名。**使用者不必阅读**：它们记录的是「当时为什么这么定」与「打算怎么做」，对排查历史决策、理解某段代码为何写成那样有用，对使用产品没用。

**`superpowers/reviews/`** —— 全项目审查报告（安全 / 代码质量），同样按日期命名。最近一份：[2026-09-03 安全审查](./superpowers/reviews/2026-09-03-security-review.md)，含分级发现、修复建议与上线前必修清单。

> 这两个目录**刻意保留在 `superpowers/` 下不迁走**：一是 CLAUDE.md 与其他文档里有若干带章节号的指针指向具体 spec（如迁移设计的 §8.1、站点爬取设计的 §5.2），迁移要同步改十来处引用；二是它是写 spec 的工具默认的写入路径，改名后新写的 spec 仍会落回这里，目录立刻分裂成两份。
