**`dev/`** —— 从 CLAUDE.md 拆出来的三份开发者参考（子系统要点 / 安全基线 / 手工验证清单）。**改到对应范围就该先读**，路由表在 [CLAUDE.md](../CLAUDE.md) 顶部，也可以跑 `./scripts/manual-smoke-hints.sh` 让它按本次改动的文件点名。
