# 结构化卡片 SP3（widget 会话恢复+历史卡片 · 表单类交互组件）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** (A) widget 刷新/断线恢复历史消息（含卡片，闭 SP1 留债）；(B) 表单类交互组件（input/select/checkbox/datetime/form/submit），提交=组装文本发出。

**Architecture:** (A) 后端 `OpenSessionResponse.Msg` 带 uiParts（反序列化 ui_spec，fail-soft）+ widget 接通死掉的 getSession 恢复历史。(B) 两渲染引擎（widget render.ts 纯 DOM、前端 registry.tsx 有状态 FormNode）加表单节点 + CARD_PROMPT 追加 form schema；submit 读本 form 字段值组装文本走 onSend/onAction。

**Tech Stack:** 后端 Spring Boot 3（单测 Mockito）；widget TS+Vite（vitest+jsdom，无 lint 靠 tsc）；前端 React19+pnpm（无 vitest，build+lint）。

## Global Constraints

- 简体中文：对话、代码注释、commit 信息；文件作者署名 `ruan`。
- 仅在 `feat/cards-sp3` 分支 commit；**不 push / merge / rebase / reset / stash / 切分支**。
- **XSS（客户面，最高优先）**：纯 DOM/React 文本节点 + `textContent`，**绝不** innerHTML 渲染模型内容；沿用结构守卫（node 非对象/null→null、children 非数组→空）+ 未知 type 忽略。用户输入值作为文本发出（安全）。
- **fail-soft**：历史卡片 uiSpec 解析失败只丢该卡、不阻断会话恢复；表单畸形节点不崩。
- **零回归**：会话恢复失败（getSession null）静默跳过、照常 ensureInbox；无表单节点时行为不变。
- 提交模型 B1：submit 组装文本走现有 `onSend`/`onAction`，**零新增后端交互**。
- `widget.js` 是提交进仓构建产物：改 widget/src 后必须 `pnpm build` 重建提交（T5）。
- 不引流式；不做专用变体；前端 ChatPage 不加载历史（本就不加载）。

    public static OpenSessionResponse of(ChatSession session, List<ChatMessage> messages,
                                         com.fasterxml.jackson.databind.ObjectMapper objectMapper) {
        return OpenSessionResponse.builder()
                .sessionId(session.getSessionId())
                .status(session.getStatus() != null ? session.getStatus().name() : null)
                .messages(messages.stream()
                        .map(m -> Msg.builder()
                                .role(m.getRole() != null ? m.getRole().name() : null)
                                .content(m.getContent())
                                .createdAt(m.getCreatedAt())
                                .uiParts(parseUiParts(m.getUiSpec(), objectMapper))
                                .build())
                        .toList())
                .build();
    }

    /** 反序列化 ui_spec JSON 为 uiParts；空/非法一律返回 null（fail-soft，历史卡片解析失败不阻断会话恢复）。 */
    private static List<com.qingyu.care.dto.UiPart> parseUiParts(
            String uiSpec, com.fasterxml.jackson.databind.ObjectMapper objectMapper) {
        if (uiSpec == null || uiSpec.isBlank()) {
            return null;
        }
        try {
            return objectMapper.readValue(uiSpec,
                    new com.fasterxml.jackson.core.type.TypeReference<List<com.qingyu.care.dto.UiPart>>() {});
        } catch (Exception e) {
            return null;
        }
    }
```

```ts
import type { OpenSessionResponse } from './api';
import type { WidgetUi } from './ui';

/** 恢复历史消息到 UI（各角色分派；ASSISTANT 带历史卡片 uiParts）。历史消息不带反馈（避免重复计量）。 */
export function restoreHistory(ui: WidgetUi, messages: OpenSessionResponse['messages']): void {
  for (const m of messages) {
    switch (m.role) {
      case 'USER':
        ui.addUserMessage(m.content);
        break;
      case 'ASSISTANT':
        ui.addBotMessage(m.content, undefined, m.uiParts);
        break;
      case 'AGENT':
        ui.addAgentMessage(m.content);
        break;
      case 'SYSTEM':
        ui.showSessionState(m.content);
        break;
      default:
        break; // 未知角色忽略
    }
  }
}
```

function wrapField(label: string, field: HTMLElement): HTMLElement {
  if (!label) return field;
  const wrap = document.createElement('div');
  wrap.className = 'qy-field-row';
  const lab = document.createElement('div');
  lab.className = 'qy-field-label';
  lab.textContent = label;
  wrap.appendChild(lab);

```tsx
import { useState } from 'react';

interface Field { type: string; name: string; label?: string; placeholder?: string; options?: string[]; }

function collectFields(node: UiNode): Field[] {
  const out: Field[] = [];
  for (const c of Array.isArray(node.children) ? node.children : []) {
    if (!c || typeof c !== 'object') continue;
    if (['input', 'select', 'checkbox', 'datetime'].includes(c.type)) {
      const p = c.props ?? {};
      out.push({ type: c.type, name: str(p.name), label: p.label ? str(p.label) : undefined,
                 placeholder: p.placeholder ? str(p.placeholder) : undefined,
                 options: Array.isArray(p.options) ? p.options.map(str) : undefined });
    }
  }
  return out;
}

function FormNode({ node, onAction }: { node: UiNode; onAction: (v: string) => void }) {
  const fields = collectFields(node);
  const [values, setValues] = useState<Record<string, string | boolean>>({});
  const submitLabel = (() => {
    const s = (Array.isArray(node.children) ? node.children : []).find((c) => c?.type === 'submit');
    return s?.props?.label ? str(s.props.label) : '提交';
  })();
  const set = (name: string, v: string | boolean) => setValues((prev) => ({ ...prev, [name]: v }));
  const submit = () => {
    const parts = fields.map((f) => {
      const v = values[f.name];
      const shown = f.type === 'checkbox' ? (v ? '是' : '否') : str(v ?? '');
      return `${f.name}: ${shown}`;
    });
    onAction(parts.join('\n'));
  };
  return (
    <div className="my-2 flex flex-col gap-2">
      {fields.map((f, i) => (
        <div key={i} className="flex flex-col gap-1">
          {f.label ? <span className="text-xs text-muted-foreground">{f.label}</span> : null}
          {f.type === 'checkbox' ? (
            <label className="flex items-center gap-2 text-sm">
              <input type="checkbox" checked={!!values[f.name]} onChange={(e) => set(f.name, e.target.checked)} />
              <span>{f.label ?? f.name}</span>
            </label>
          ) : f.type === 'select' ? (
            <select className="border rounded px-2 py-1 text-sm" value={str(values[f.name] ?? '')} onChange={(e) => set(f.name, e.target.value)}>
              <option value=""></option>
              {(f.options ?? []).map((o, j) => <option key={j} value={o}>{o}</option>)}
            </select>
          ) : (
            <input type={f.type === 'datetime' ? 'date' : 'text'} className="border rounded px-2 py-1 text-sm"
                   placeholder={f.placeholder} value={str(values[f.name] ?? '')} onChange={(e) => set(f.name, e.target.value)} />
          )}
        </div>
      ))}
      <Button size="sm" className="self-start" onClick={submit}>{submitLabel}</Button>
    </div>
  );
}
```
在 `renderNode` switch 加：
```tsx
    case 'form':
      return <FormNode key={key} node={node} onAction={onAction} />;
    case 'input': case 'select': case 'checkbox': case 'datetime': case 'submit':
      return null; // 字段/提交由所属 FormNode 统一渲染，孤立出现时忽略
```
> 所有 label/option/placeholder 经 `str` 走 React 文本节点/受控属性，无 XSS。字段值受控 state，submit 组装文本走 onAction（= ChatPage 的 send 回填）。
