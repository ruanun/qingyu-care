# 结构化卡片 SP2（widget 纯 DOM 渲染引擎）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** 在可嵌网页的独立 Widget（Shadow DOM）内用纯 DOM 引擎渲染 AI 返回的结构化卡片（uiParts），XSS 安全、按钮点击回填、重建并提交 `widget.js`。

**Architecture:** 后端 SP1 已让 `/open/v1/chat/completions`（widget 走的口）返回 `uiParts`。widget 侧新增 `render.ts`（SP1 `registry.tsx` 的纯 DOM 移植）+ 卡片样式，`ui.ts`/`main.ts` 接线，按钮点击 = 发合成消息。

**Tech Stack:** TypeScript + Vite（widget 独立子项目，pnpm）；Shadow DOM；vitest + jsdom（无 lint 脚本，靠 build 的 tsc 把类型关）。

## Global Constraints

- 简体中文：对话、代码注释、commit 信息；文件作者署名 `ruan`。
- 仅在 `feat/cards-sp2` 分支 commit；**不 push / 不 merge / 不 rebase / 不 reset / 不 stash / 不切分支**。
- **XSS（客户面，最高优先）**：纯 DOM + `textContent`，**绝不** `innerHTML` 渲染模型内容；`image` URL 走 `safeUrl`（仅 http/https + 长度上限）；未知 `type` → 返回 null 忽略；结构守卫（node 非对象/null → null、children 非数组 → 空）防畸形节点崩渲染。
- **零回归**：无 `uiParts` 或全 text 片段 → 回退纯文本 `reply`，与现状逐字节一致。
- 按钮点击 = 发合成用户消息（调 widget 的 `onSend`），零新增后端接口。
- `widget.js` 是**提交进仓的构建产物**：改 `widget/src` 后必须 `pnpm build` 重建并提交（`.gitattributes` 强制 LF）。
- 全部在 shadow root 内，不污染宿主页；不引 React。

- [ ] **Step 4: 写 render.ts**

```ts
import type { UiNode } from './api';

/** 仅允 http/https 且长度受限，其余返回空串（防 javascript:/data: 注入）。 */
export function safeUrl(u: unknown): string {
  if (typeof u !== 'string' || u.length > 2048) return '';
  try {
    const p = new URL(u);
    return p.protocol === 'http:' || p.protocol === 'https:' ? u : '';
  } catch {
    return '';
  }
}

function str(v: unknown): string {
  return v == null ? '' : String(v);
}

function el(tag: string, className?: string): HTMLElement {
  const e = document.createElement(tag);
  if (className) e.className = className;
  return e;
}

/**
 * 纯 DOM 递归渲染单个 UiNode（SP1 registry.tsx 的 DOM 移植）。
 * 结构守卫：node 非对象/null、未知 type 一律返回 null（静默忽略、不抛、不阻断其余卡片）——fail-soft。
 * 全部 textContent 渲染，绝不 innerHTML；image URL 经 safeUrl 白名单。
 */
export function renderNode(
  node: UiNode | null | undefined,
  onAction: (value: string) => void,
): HTMLElement | null {
  if (!node || typeof node !== 'object') return null;
  const p = node.props ?? {};
  const childNodes = Array.isArray(node.children) ? node.children : [];
  const renderKids = (parent: HTMLElement) => {
    for (const c of childNodes) {
      const child = renderNode(c, onAction);
      if (child) parent.appendChild(child);
    }
  };

  switch (node.type) {
    case 'card': {
      const card = el('div', 'qy-card');
      if (p.title != null && str(p.title) !== '') {
        const title = el('div', 'qy-card-title');
        title.textContent = str(p.title);
        card.appendChild(title);
      }
      const body = el('div', 'qy-card-body');
      renderKids(body);
      card.appendChild(body);
      return card;
    }
    case 'text': {
      const t = el('div', p.emphasis ? 'qy-node-text qy-emph' : 'qy-node-text');
      t.textContent = str(p.value ?? p.text);
      return t;
    }
    case 'kv': {
      const kv = el('div', 'qy-kv');
      const label = el('span', 'qy-kv-label');
      label.textContent = str(p.label);
      const value = el('span', 'qy-kv-value');
      value.textContent = str(p.value);
      kv.appendChild(label);
      kv.appendChild(value);
      return kv;
    }
    case 'badge': {
      const b = el('span', 'qy-badge');
      b.textContent = str(p.text ?? p.value);
      return b;
    }
    case 'divider':
      return el('div', 'qy-divider');
    case 'image': {
      const src = safeUrl(p.src ?? p.url);
      if (!src) return null;
      const img = el('img', 'qy-node-img') as HTMLImageElement;
      img.src = src;
      img.alt = str(p.alt);
      return img;
    }
    case 'button': {
      const btn = el('button', 'qy-card-btn');
      (btn as HTMLButtonElement).type = 'button';
      btn.textContent = str(p.label);
      btn.addEventListener('click', () => onAction(str(p.value ?? p.label)));
      return btn;
    }
    case 'actions': {
      const a = el('div', 'qy-actions');
      renderKids(a);
      return a;
    }
    case 'list': {
      const ul = el('ul', 'qy-list');
      for (const c of childNodes) {
        const child = renderNode(c, onAction);
        if (child) {
          const li = document.createElement('li');
          li.appendChild(child);
          ul.appendChild(li);
        }
      }
      return ul;
    }
    case 'row': {
      const r = el('div', 'qy-row');
      renderKids(r);
      return r;
    }
    case 'column': {
      const col = el('div', 'qy-col');
      renderKids(col);
      return col;
    }
    default:
      return null; // 未知 type 忽略，不报错
  }
}
```
